# Student Report Management System

A simple console-based Student Report Management System developed in Python using CSV file handling.  
This project allows administrators to manage student records and users to view their own details.

---

## Features

### Admin Functions
- Add new student records
- Delete existing student records
- Display all student records
- Search student records by ID
- Secure admin login system

### User Functions
- View personal student details using Student ID

---

## Technologies Used

- Python
- CSV File Handling
- OS Module
- Getpass Module

---

## Project Structure

```text
├── Project.py        # Main Python source code
├── student.csv       # Stores student records
├── README.md         # Project documentation
```

## Student Record Fields

Each student record contains:

- Student ID
- Student Name
- Attendance
- Computer Science Marks
- Physics Marks
- Chemistry Marks
- Maths Marks
- Physical Education Marks
